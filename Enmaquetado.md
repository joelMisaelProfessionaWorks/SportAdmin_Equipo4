# ⚽ Club Deportivo León Saltillo - SportAdmin
Sistema integral de gestión web para clubes deportivos, equipos y administración de torneos. 
> **Nota:** Este repositorio contiene la **versión estática (Maqueta / Front-end)** del proyecto para propósitos de presentación. La lógica completa del backend y la base de datos se maneja a través de PHP, MySQL y Docker en el entorno de desarrollo.
## 📋 Características Principales
* **Gestión de Usuarios y Roles:** Diferentes niveles de acceso (Administradores, Encargados de liga, etc.).
* **Administración de Equipos y Jugadores:** Registro y control del roster.
* **Rol de Juegos:** Programación de partidos, fechas, horas y asignación de canchas.
* **Tabla de Posiciones:** Seguimiento de victorias, derrotas y goles.
* **Control de Finanzas:** Registro de pagos, inscripciones, arbitraje y abonos.
* **Diseño Responsivo:** Interfaz gráfica moderna (UI/UX) temática para el ámbito futbolístico.
## 💻 Tecnologías Utilizadas
* **Front-end:** HTML5, CSS3, JavaScript (Vanilla).
* **Back-end (Versión Completa):** PHP 8, PDO.
* **Base de Datos:** MySQL.
* **Despliegue y Contenedores:** Docker & Docker Compose.
